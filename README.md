# 🌿 EcoParaíso - Landing Page Turística

Proyecto web desarrollado con **HTML, CSS y JavaScript** para promocionar un sitio turístico ecológico llamado **EcoParaíso Hotel - Restaurante**.

El sistema incluye una landing page moderna y responsive con módulos de habitaciones, galería, reservaciones, contacto y ubicación.

---

# 📌 Características del Proyecto

✅ Diseño moderno y responsive  
✅ Landing page turística  
✅ Módulo de habitaciones  
✅ Galería de imágenes  
✅ Formulario de reservaciones  
✅ Formulario de contacto  
✅ Integración con Google Maps  
✅ Efectos visuales con CSS  
✅ Validaciones básicas con JavaScript  
✅ Organización profesional de carpetas  

---

# 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript Vanilla
